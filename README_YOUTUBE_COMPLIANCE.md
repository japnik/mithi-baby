This script demonstrates exactly how Mithi Baby interacts with the YouTube Data API.

### What it demonstrates:
- **Authentication**: Usage of OAuth 2.0 (via `token.pickle`) to access the authenticated user's YouTube channel.
- **Metadata Management**:
  - **Dynamic Titles**: Automatically generating titles like `Ishaan — Personalized Punjabi Lori (Feb 2026) | Mithi Baby`.
  - **Descriptions**: Formatting descriptions that include the user's generated lyrics and heritage-focused messaging.
  - **Compliance Settings**: Explicitly setting `madeForKids=True` and `selfDeclaredMadeForKids=True` for baby content.
  - **Classification**: Assigning the content to Category ID `10` (Music).
- **Video Upload**: Byte-by-byte resumable upload of the generated MP4 file.

### How to use:
1. Ensure your `backend/auth/token.pickle` is valid (run `python backend/utils/setup_youtube_auth.py` if needed).
2. Run the script:
   ```bash
   python youtube_compliance_demo.py
   ```

## 3. Implementation Rationale (for YouTube Team)

Mithi Baby uses the YouTube API to allow parents to share their newly created, personalized lullabies with their families worldwide. 

- **Data Privacy**: We only access the `youtube.upload` scope. We do not read user's private data or other videos.
- **Content Policy**: All content uploaded is generated by our AI pipeline (Mithi Baby) and belongs to the user who initiated the creation.
- **Child Safety**: We strictly enforce the `madeForKids` flag on every upload, ensuring compliance with COPPA and YouTube's child safety policies.
